# LOCKSTEP — Your deadline, locked in.

**A Gemini-planned countdown lock screen.** LOCKSTEP turns a distant deadline into:

1. a **feasibility-checked milestone plan.** Google Gemini drafts it as structured JSON; plain code then checks every date, every working day and your real capacity, and you approve each milestone;
2. a **timezone-accurate live countdown** with today's focus, progress, pace and streaks;
3. a **premium lock-screen wallpaper** (8 templates × 6 themes, native phone resolution) showing days left, the next milestone and real progress, so the deadline is visible every time you unlock your phone;
4. an **adaptive AI coach** that can read your plan and progress (function calling) and *propose* a replan as an old → new diff you accept or reject.

**Signature idea, the Living Wallpaper:** a private, revocable URL that always returns *today's* wallpaper. An iPhone Shortcuts automation that you set up once can apply it every morning. LOCKSTEP never changes your phone by itself.

Built for the Handshake AI × Google Gemini challenge "Your Deadline, Your Design".

## Quick start

```bash
npm ci
cp .env.example .env        # add GEMINI_API_KEY (server-side only)
npm run dev                 # http://localhost:5173 (API on :8787)
```

Everything except the AI features works with no key: guest mode, offline, the manual plan, the countdown, Studio, export, insights and settings. Deploy steps, Upstash, Supabase and the iPhone automation are in **[docs/SETUP.md](docs/SETUP.md)**.

| Command | What it does |
|---|---|
| `npm run build` | typecheck → Vite build → API bundle for Vercel → secret-leak check |
| `npm start` | one Node server for the built app and the API (Cloud Run / local prod) |
| `npm test` | unit + integration tests (Gemini mocked with MSW in tests only) |
| `npm run test:live` | real Gemini smoke test (reports **SKIPPED** without a key) |
| `npm run test:e2e` | Playwright acceptance flow at 360/390/430/1440 px + axe accessibility sweep |
| `npm run submission -- --url <live-url>` | rebuilds every Handshake asset from the real app |

## How it works

```
Browser (React 19, local-first IndexedDB) ──/api──▶ Express (Vercel function / Node)
  wizard → SSE stream ──────────────────────────▶ Gemini (structured JSON, streamed)
  review ◀── validated plan + code checks ◀──── zod shape + deterministic checks (+1 repair)
  Studio (Canvas 2D renderer) ── same renderer ──▶ server PNG for Living Wallpaper links
```

- **Gemini engine** (`server/gemini/`): `@google/genai`, newest stable Flash model auto-picked, `responseJsonSchema`, SSE streaming with milestones parsed as they arrive, one repair call with the exact errors, 30 s timeouts, backoff on 429/503, heavy → default model fallback, per-IP rate limits (Upstash when configured), prompt-injection delimiters, and an `ai_runs` log of model, latency, ok and tokens (never text or keys).
- **Code is the judge** (`shared/plan.ts`): every date after today, on or before the deadline, chronological, on your working days; capacity = working days × hours/day; feasibility recomputed in code and shown beside Gemini's.
- **Countdown engine** (`shared/time.ts`): UTC + IANA zone per goal, explicit DST gap/overlap handling, one shared 1-second ticker that pauses when the tab is hidden.
- **Wallpaper renderer** (`shared/wallpaper/`): one Canvas 2D renderer for browser and server, safe zones per device, automatic contrast scrims (≥ 4.5:1), deterministic grain, PNG size checked from the header on every export.
- **Honesty:** "✦ AI suggestion", "Approved", "Edited by you", "Completed" and "Generated by Gemini · time" labels; wallpapers never show ticking seconds (Focus Mode does); when Gemini is unavailable the app says so, and your saved plan keeps working.

## Project map

```
src/        React app (features/: wizard, planning, review, goals, studio, insights, coach, settings, landing, cover)
shared/     code shared by browser + server: time, plan rules, API types, wallpaper renderer
server/     Express API: gemini/, lib/ (rate limit, retry, SSE, errors), wallpaper/ (PNG + Living links)

tests/      unit, integration (MSW), live (real Gemini, auto-skipped)
e2e/        Playwright acceptance + accessibility (test-only Gemini mock)
docs/       PROGRESS (status + evidence), DECISIONS, SETUP, notes, evidence screenshots
submission/ Handshake assets + CHECKLIST.md
```
